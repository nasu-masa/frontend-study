# React Basics

Reactの基礎学習用リポジトリです。
教材で学習した内容を、自分で再実装しながら記録しています。

## 学習目的

* Reactの基本概念の理解
* JSXの書き方の習得
* コンポーネント設計の基礎理解
* Props、StateなどのReactの基本機能の習得
* GitHub上で学習履歴を管理すること

## 開発環境

* Node.js 22
* React
* Vite

## 学習内容

* [x] コンポーネント

## ディレクトリ構成

src/components 配下に学習内容ごとのサンプルを配置しています。

例：

* `01-components`
* `02-props`
* `03-usestate`

## 起動方法

```bash
npm install
npm run dev
```

## 備考

教材のコードをそのまま保存するのではなく、理解した内容を自分で再実装しながら学習を進めています。
